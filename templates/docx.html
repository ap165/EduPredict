EduPredict API

A machine-learning API for predicting students' next-semester CGPA, classifying academic performance, and estimating backlog risk.

PREDICTION ENDPOINTS03CGPA · Performance · Backlog
HTTP METHODPOSTJSON request body
API PREFIX/api/v1Versioned routes

BASE URL · LOCAL DEVELOPMENT

http://127.0.0.1:5000

AVAILABLE ENDPOINTS

POST/api/v1/predictions/cgpaPredict CGPA
POST/api/v1/predictions/performanceClassify performance
POST/api/v1/predictions/backlog-riskPredict backlog status
01

Authentication

The current prediction routes do not require an API key or login.

i

No authentication required: send requests directly to the endpoints. Add authentication and rate limiting before exposing the API publicly.

02

Request format

All prediction endpoints accept a JSON object in the request body.

CONTENT TYPE

Content-Type: application/json

HTTP METHOD

POST

Send the feature names exactly as shown in each endpoint's request example. Values must use the same formats and categories used when the corresponding model was trained.

03

CGPA prediction

POST

Predict a student's next-semester CGPA on a 10-point scale.

/api/v1/predictions/cgpa

Request body

JSON
{
  "class_12_percentage": 79,
  "class_10_percentage": 75,
  "family_income": "Upper middle (30,000-50,000)",
  "hometown": "City",
  "exam_preparation": "2-3 Hours",
  "gaming_hours": "0-1 Hour",
  "attendance_percentage": "80%-100%",
  "previous_semester_cgpa": 8.2
}

Input parameters

FieldTypeDescription
class_12_percentageNumberClass 12 percentage.
class_10_percentageNumberClass 10 percentage.
family_incomeStringIncome category used in training data.
hometownStringFor example, City or Village.
exam_preparationStringFor example, 0-1 Hour, 2-3 Hours, More than 3 Hours.
gaming_hoursStringGaming-time category used in training data.
attendance_percentageStringAttendance band, for example 80%-100%.
previous_semester_cgpaNumberPrevious semester CGPA, on a 0–10 scale.

Example response

200 · JSON
{
  "success": true,
  "prediction": {
    "predicted_next_semester_cgpa": 8.35
  }
}
04

Performance prediction

POST

Classify the student's expected academic performance category.

/api/v1/predictions/performance
↳

This endpoint uses the same eight input fields and value formats as the CGPA prediction endpoint.

Request body

JSON
{
  "class_12_percentage": 79,
  "class_10_percentage": 75,
  "family_income": "Upper middle (30,000-50,000)",
  "hometown": "City",
  "exam_preparation": "2-3 Hours",
  "gaming_hours": "0-1 Hour",
  "attendance_percentage": "80%-100%",
  "previous_semester_cgpa": 8.2
}

Example response

200 · JSON
{
  "success": true,
  "prediction": {
    "performance": "Very Good"
  }
}

Possible categories: Excellent, Very Good, Good, Average, and Poor. The exact result is returned by the trained model.

05

Backlog risk prediction

POST

Predict whether the student is classified as Backlog or No Backlog.

/api/v1/predictions/backlog-risk

Request body

JSON
{
  "previous_semester_cgpa": 6.8,
  "attendance_percentage": 65,
  "previous_backlogs": 1,
  "study_time_hours_per_day": 2.5
}

Input parameters

FieldTypeDescription
previous_semester_cgpaNumberPrevious semester CGPA, on a 0–10 scale.
attendance_percentageNumberAttendance percentage from 0 to 100.
previous_backlogsIntegerNumber of previous backlogs.
study_time_hours_per_dayNumberAverage study hours per day.

Example response

200 · JSON
{
  "success": true,
  "prediction": {
    "backlog_status": "No Backlog"
  }
}
!

Prototype limitation: the backlog model was trained using synthetic records and synthetic labels. Its output is for project demonstration and must not be treated as a validated real-world failure-risk assessment.

07

Errors & responses

Responses use JSON so they can be handled easily by web and mobile clients.

Error response format

JSON · Example
{
  "success": false,
  "error": "Description of the error"
}
StatusMeaning
200Prediction request completed successfully.
400The request could not be processed. Check the JSON body and input values.
404The requested route does not exist.
500Unexpected server-side error.

The 400 error format reflects the route handlers shown in this project setup. Ensure your Flask error handlers return the same format if you add more validation.

08

Frontend integration

Example of calling the CGPA endpoint from browser JavaScript.

JavaScript · Fetch
const response = await fetch(
  "/api/v1/predictions/cgpa",
  {
    method: "POST",
    headers: {
      "Content-Type": "application/json"
    },
    body: JSON.stringify({
      class_12_percentage: 79,
      class_10_percentage: 75,
      family_income: "Upper middle (30,000-50,000)",
      hometown: "City",
      exam_preparation: "2-3 Hours",
      gaming_hours: "0-1 Hour",
      attendance_percentage: "80%-100%",
      previous_semester_cgpa: 8.2
    })
  }
);

const result = await response.json();
console.log(result);

When the frontend is served by the same Flask application, a relative URL such as /api/v1/predictions/cgpa is sufficient.
