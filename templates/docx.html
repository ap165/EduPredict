EduPredict API

API endpoint reference · v1

Base URLhttp://127.0.0.1:5000/api/v1

CGPA Prediction

POST/predictions/cgpa

Example request

curl -X POST http://127.0.0.1:5000/api/v1/predictions/cgpa \
  -H "Content-Type: application/json" \
  -d '{
    "class_12_percentage": 79,
    "class_10_percentage": 75,
    "family_income": "Upper middle (30,000-50,000)",
    "hometown": "City",
    "exam_preparation": "2-3 Hours",
    "gaming_hours": "0-1 Hour",
    "attendance_percentage": "80%-100%",
    "previous_semester_cgpa": 8.2
  }'

Example output

{
  "success": true,
  "prediction": {
    "predicted_next_semester_cgpa": 8.35
  }
}
